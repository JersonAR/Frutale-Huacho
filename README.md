# Frutale · Huacho

Web one-page estática (HTML, CSS y JavaScript, sin compilación): arma tu vaso de fresas con crema capa por capa, carta completa, pedidos por WhatsApp y el logo animado.

- **Precios, carta, reglas del vaso, sedes, horario y número de WhatsApp:** `js/carta-data.js`
- **Logo:** `img/frutale-logo.svg` (vectorizado por capas); `js/logo.js` lo inserta en línea para animarlo.
- **Publicación:** Cloudflare, en https://frutalehuacho.roxanjer.com
